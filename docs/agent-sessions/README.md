# Registros de sesiones de agentes

Cada agente que modifique código crea un archivo `YYYY-MM-DD-HHMM-<agent>.md` usando `templates/AGENT_SESSION_LOG.md`. El registro documenta fuentes consultadas, supuestos, invariantes, archivos tocados y validación ejecutada.

No incluir chain-of-thought ni información secreta. Registrar únicamente razones técnicas resumidas, evidencia verificable y decisiones necesarias para reproducibilidad.
